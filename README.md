# Urlaubssuche

Browser-App zur Urlaubsplanung: Entscheidungsbaum, Live-Suche nach Zielen (Wikipedia, Wikivoyage, OpenStreetMap), Kostenschätzung, Karten, Export als PDF und Markdown.

- Online: https://bastian-lueckert.github.io/urlaubssuche/
- Änderungen pro Version: [CHANGELOG.md](CHANGELOG.md)
- Ältere Stände: Ordner `versions/`

Die App läuft komplett im Browser. Eingaben werden nur lokal im Browser gespeichert.
